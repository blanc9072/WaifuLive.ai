Terminal 1 — Python backend (FastAPI + Gemini Live relay, both in one process):

    cd ~/Documents/Real\ Waifu\ copy
    source .venv/bin/activate
    python main.py

    Windows 11 (PowerShell):
      cd "C:\Users\andre\Dev\Real Waifu copy"
      .venv\Scripts\Activate.ps1
      python main.py
    (First time only — create the venv and install deps first:
      python -m venv .venv
      .venv\Scripts\Activate.ps1
      pip install fastapi uvicorn websockets google-genai
     If "running scripts is disabled" appears, run once:
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned)

    Serves:
      http://localhost:8000  — chat / memory / sleep API
      ws://localhost:8765    — voice WebSocket relay (Gemini Live)

    npm start

    Windows 11 (PowerShell):

    On first launch shows the login screen.
    After login: Live2D model window + chat window appear.
    Hotkeys:
      Cmd+Shift+P  toggle chat window        (Windows: Ctrl+Shift+P)
      Cmd+Shift+O  toggle model visibility   (Windows: Ctrl+Shift+O)
      Cmd+Shift+M  toggle mic (voice mode)   (Windows: Ctrl+Shift+M)
